# Weather

## Сборка и запуск
1. Открыть проект в IntelliJ IDEA с JDK 21.
2. Добавить `pom.xml` как Maven Project.
> Использовалась сторонняя библиотека Jackson, поэтому без этого не выйдет
3. В конфигурации запуска `WeatherApplication` добавить переменную окружения `YANDEX_WEATHER_API_KEY`.
4. Запустите `src/WeatherApplication.java` в IDE.
